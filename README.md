## Description
CSC-221 is Introduction To Problem Solving and Programming in Python

For my first assignment in CSC-221 I had to create an app using Python's Turtle library that would create an image.

I decided that I would use turtle to make a primitive drawing system, connecting points to each other.

This app in its current state creates the python logo, but it may be modified to make any pattern.
